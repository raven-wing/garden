# Słownik Wyrazów Swojskich (SWS)
# D
**Dwumlask** (ang. double click) - gest myszą wymagany do otworzenia programu lub aplikacji (autor: Jan Bielecki)
# G
**Grozmieniacz** (ang. game changer) - rzecz sprawiająca zwrot w postrzeganiu rzeczywistości.
Przykład: *Odkrycie, że dinozaury miały pióra było grozmieniaczem. Od tej pory wszystkie dinozaury rysujemy inaczej*
# M
**Międzymordzie** (ang. interface) - sposób połączenia dwóch technologii/protokołów (autor: Jan Bielecki)
# P
**Pan w środeczku** (ang. man in the middle) - kategoria ataków (głównie hakerskich) polegających na "wpięciu się" niepostrzeżenie pomiędzy "wódkę a zakąskę". Istotnym jest tu słowo "niepostrzeżenie".
