easy pinning tags of github actions to sha

# why?

Github allows to change tags.
If one would like to move tag to another version of code, he can. 

This may lead to changing harmless say-hello@v1.0.0 action which is just printing 'hello world' into printing you social security number instead. Even though it seems that you pinned version.

# better?

Hey, github guys!
Stop using tags or make it locked.
